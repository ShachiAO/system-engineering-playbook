# IDEF3 Диаграммы сценариев процессов

В данном приложении представлены диаграммы процессного моделирования IDEF3,
описывающие сценарии выполнения ключевых функций системы автоматизированного
анализа НДС с использованием искусственного интеллекта.

IDEF3-диаграммы отражают логическую последовательность, ветвления и альтернативные
пути выполнения процессов, возникающие в ходе обработки данных по НДС.
